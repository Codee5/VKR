#  ИС мониторинга психологического состояния учащихся

> 

## О проекте

Интеллектуальная информационная система мониторинга, анализа и прогнозирования психологического состояния учащихся, разработанная для автоматизации деятельности педагога-психолога в **ГБОУ Школа № 1533 «ЛИТ»** (г. Москва).

Система позволяет:
- вести электронный журнал индивидуальных консультаций и групповых тестирований;
- автоматически кластеризовать учащихся по уровню тревожности (3 кластера);
- формировать аналитические отчёты и диаграммы;
- **прогнозировать вероятность возникновения психологических проблем** на основе алгоритма машинного обучения — дерева решений (Decision Tree, критерий Джини, max_depth=5).

## Алгоритм прогнозирования

Модуль прогнозирования реализует бинарную классификацию на основе **дерева решений** (без sklearn — чистый Python):

**Признаковое пространство (x1–x7):**

| Признак | Описание |
|---------|----------|
| x1 | Уровень тревожности по последнему тестированию |
| x2 | Количество обращений на консультацию |
| x3 | Динамика тревожности (изменение относительно предыдущего) |
| x4 | Кластер по последнему тестированию (1/2/3) |
| x5 | Психотип учащегося (кодируется Label Encoding) |
| x6 | Количество уникальных типов проблем |
| x7 | Номер класса (возрастная группа) |

**Нормализация:** Min-Max — `x' = (x - x_min) / (x_max - x_min)`

**Интерпретация показателя В_п:**

| Диапазон В_п | Уровень риска |
|-------------|--------------|
| 0.00 — 0.29 | Низкий |
| 0.30 — 0.59 | Умеренный |
| 0.60 — 0.79 | Высокий |
| 0.80 — 1.00 | Критический |

## Быстрый старт

### Требования
- Python 3.10+
- pip

### Установка и запуск

```bash
git clone https://github.com/Codee5/psych-system-mvp.git
cd psych-system-mvp
pip install -r requirements.txt
python app.py
```

Открыть в браузере: **http://localhost:5050**

```
Логин:  psycholog
Пароль: lit1533
```

При первом запуске база данных создаётся автоматически и заполняется тестовыми данными: 10 учащихся, 2 тестирования, 10 консультаций.
